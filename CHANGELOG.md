# Changelog

All notable changes to the AEGIS-X project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-06

### Added
- **Foundation Architecture & Ingestion**: MQTT simulator, sensor simulation, telemetry collector, and persistent SQLite storage.
- **Anomaly Detection Engine**: Sliding-window feature extraction, statistical thresholding, Isolation Forest models, and unified anomaly scoring.
- **Investigation Pipeline**: Asset topology enrichment, alert correlation, incident clustering, attack graph reasoning, ATT&CK for ICS mapping, and risk prioritization.
- **Grounded AI Investigator**: Timeline reconstruction, evidence bundle construction, uncertainty quantification, grounded narrative synthesis, and citation faithfulness evaluation.
- **Autonomous Orchestration**: DAG task planning, safe tool execution registry, evidence acquisition loop, dynamic hypothesis re-evaluation, and tamper-evident SHA-256 decision ledger.
- **Case Management & Provenance**: Investigation case store, analyst feedback engine, confidence adjustment, and SHA-256 evidence chain-of-custody provenance.
- **Human-Approved Response**: Response playbooks, mandatory approval policy gates, response execution engine, and action rollback capabilities.
- **Research Benchmarking**: Quantitative evaluation suite, comparative Markdown & LaTeX publication table generator.
- **Unified Frontend**: Landing page with branded copy, glassmorphism design system, particle canvas, scroll animations, and interactive enterprise command center dashboard.
- **REST API**: Full OpenAPI endpoints for alerts, incidents, cases, investigation narratives, response plans, and system status.
