# AEGIS-X Strategic Roadmap

This document outlines the high-level roadmap and architectural milestones for AEGIS-X.

---

## 📍 Current Release: v1.0.0 (Foundation Release)

- [x] **Phase 0 — Foundation & Architecture**: Modular directory layout, configuration schemas, design system tokens.
- [x] **Phase 1 — Telemetry Ingestion**: MQTT sensor simulator, OPC UA / Modbus abstractions, SQLite storage.
- [x] **Phase 2 — Anomaly Detection**: Sliding-window feature extraction, statistical thresholding, Isolation Forest models, unified scoring.
- [x] **Phase 3 — Incident Correlation**: Asset topology enrichment, alert correlation, attack graphs, ATT&CK for ICS mapping.
- [x] **Phase 4 — Grounded AI Investigator**: Timeline reconstruction, evidence bundle construction, uncertainty quantification, narrative synthesis, faithfulness evaluation.
- [x] **Phase 5 — Autonomous Orchestration**: DAG task planning, safe tool execution, evidence acquisition loop, hypothesis re-evaluation, decision auditability.
- [x] **Phase 6 — Workflow & Provenance**: Case management lifecycle, analyst feedback engine, confidence adjustment, SHA-256 evidence chain-of-custody.
- [x] **Phase 7 — Human-Approved Response**: Response playbooks, mandatory approval policy gates, execution engine, reversible action rollback.
- [x] **Phase 8 — Research Benchmarks**: Quantitative evaluation suite, comparative LaTeX publication tables.

---

## 🔮 Future Horizons

### Short-Term (v1.1 - v1.2)
- **Digital Twin Simulation**: High-fidelity PLC process simulation with live physics feedback loops.
- **Enhanced Enterprise Web UI**: Multi-tenant dashboard, real-time WebSocket event streaming, interactive D3 attack graph rendering.
- **Expanded Protocol Collectors**: Native BACnet, Modbus TCP, and Ethernet/IP collector integrations.

### Medium-Term (v1.5 - v2.0)
- **Distributed Multi-Agent Swarms**: Edge-deployed micro-agents for autonomous local anomaly containment.
- **Zero-Trust OT Authorization**: Hardware token & cryptographically signed approval keys for critical industrial actions.
- **Academic Publication Suite**: Fully reproducible benchmarking artifacts and standardized dataset generation.
