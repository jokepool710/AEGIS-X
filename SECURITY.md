# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

AEGIS-X is dedicated to maintaining the security and safety of critical industrial cybersecurity research. If you discover a security vulnerability within this repository or platform, please follow these steps:

1. **Do NOT open a public GitHub issue.**
2. Send a security report to `security@aegis-x.org` or report via GitHub Private Vulnerability Reporting.
3. Include detailed reproduction steps, proof-of-concept scripts, and affected components.
4. The AEGIS-X maintainers will respond within 48 hours and provide a timeline for remediation.

## Responsible Conduct & Defensive Use

AEGIS-X is intended strictly for defensive security research, authorized testing, educational demonstrations, and isolated cyber-range experimentation. Attack scenarios and telemetry generation must only be executed against systems you own or are explicitly authorized to test.
